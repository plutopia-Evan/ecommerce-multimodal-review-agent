# 产品方案

## 背景

电商平台的评价区同时存在真实好评、客观差评、低信息评价、攻击性内容和批量套模板评价。仅依靠关键词或情感极性会误伤真实消费者反馈，也无法识别固定结构改写。

## 产品目标

1. 自动识别明确恶意评价。
2. 保护描述真实商品问题的客观差评。
3. 使用同商品历史评价检测模板复用。
4. 将图片质量和图片恶意信号纳入最终判断。
5. 对不确定或系统异常结果保留人工复核出口。

## 关键规则

- 文字出现辱骂攻击、广告导流、明显无关、凑字数或严重混乱时，可直接判为恶意。
- 负面表达未命中恶意类型时，保留为客观差评。
- 长评价在未命中文字恶意或客观差评后，进入 RAG 套模板检测。
- 任意图片命中广告导流等恶意类型时，图片结论为恶意。
- 没有恶意图片且至少存在一张正常图片时，图片结论为正常。
- 没有恶意图片且不存在正常图片时，图片结论为低质量。
- 文字或图片任一分支命中恶意时，最终结论为恶意。
- 模型或解析异常时转人工复核，避免错误屏蔽。

## 主要指标

- 恶意评价召回率
- 客观差评误杀率
- 套模板识别准确率
- 人工复核率
- 单次调用成本
- 平均耗时与 P95 耗时

## 已知限制

- 图像真实性仅依靠视觉模型判断，无法完成取证级鉴伪。
- 小规模知识库中的相似度分数不能直接推广到所有商品类目。
- 模型供应商、插件版本和提示词变更可能影响分类边界，应持续进行回归测试。
